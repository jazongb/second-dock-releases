## SecondDock 0.3.1 (5)

The first release built for Three Cedars staff and physician colleagues.

**New**
- Secure Send tile (Three Cedars profile). One click opens the clinic Hub page where you encrypt a PDF before emailing it to a patient.
- Two starting profiles on first run: Three Cedars for clinic staff, and Physician, which adds the diagnostic-code and WorkSafeBC lookups.

**Improved**
- OCR now runs entirely inside SecondDock using Apple Vision, with no separate helper to install.
- Dosing: the per-injection amount can be edited directly.
- Tiles show a refresh ring while their data updates.

**Fixed**
- First-run setup is detected correctly, and windows no longer open underneath the strip.
